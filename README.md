# Codex Skin（Windows 实验版）

版本 0.2.0：修复整个窗口误套用侧栏遮罩导致背景过淡的问题。主内容只保留一次遮罩，真正的侧栏单独绘制底色。预览按真实客户端的嵌套标记、340 px 侧栏、标题栏和输入框区域重做，可切换首页与聊天视图。升级时可安全接管另一个解压目录中的本工具监听器。

同时保留 0.1.1 的启动时序修复：跳过尚无 html/body 或正在导航的辅助窗口，不影响已就绪的主窗口。

参考 TRAE CN Skin 的本地调试端口注入方式，为 Codex 桌面版添加自选背景图。
不修改安装文件，不写入客户端主题设置，不读取或导出聊天内容。

默认背景是此前生成的第三张「暗调沉静」，另外两张也在 `materials/` 中。

## 第一次使用

1. 完整解压这个文件夹，放到以后不会随意删除的位置。
2. 安装 Node.js 22 或更新版本。当前这台电脑已经满足；无需 `npm install`。
3. 可以先双击 `preview.bat` 看离线模拟效果。它不会修改客户端。
4. 保存工作，自己完全退出 Codex / ChatGPT 桌面客户端，包括托盘图标。
5. 双击 `start.bat`。脚本会自动找安装目录，以本机调试模式启动客户端并应用皮肤。
6. 以后要带背景图使用，就通过 `start.bat` 启动。成功后窗口约三秒关闭。

脚本不会主动退出、重启或终止你的客户端。若客户端已经启动但没有开放调试端口，会停下来提示你自行退出。
当前版本的应用显示名与进程名可能是 ChatGPT，但安装包名仍为 OpenAI.Codex，脚本同时识别这两种名称。

## 换图片

双击 `change-image.bat`：

- 输入 `1`：清冷冬日。
- 输入 `2`：温柔日常。
- 输入 `3`：暗调沉静（默认）。
- 直接按回车：弹出文件选择框，选择自己的 JPG、PNG 或 WebP 图片。

图片不超过 8 MiB。脚本会检查真实格式、复制图片、更新深浅色配置，随后打开预览。
后台监听器正在运行时，换图和改配置通常在下一轮检查（约三秒，加上图片解码时间）后生效。
旧图片文件保留在 themes 中，方便回退；不会自动清理你的图片。

## 调整透明度和位置

`themes/dark.json` 和 `themes/light.json` 分别对应客户端深浅色模式。只改数字，保留 JSON 格式：

| 字段 | 范围 | 含义 |
| --- | --- | --- |
| `imageOpacity` | 0–100 | 图片本身的不透明度，越大越明显 |
| `surfaceOpacity` | 0–100 | 主内容区的遮罩，越大文字越容易读、图片越淡 |
| `sidebarOpacity` | 0–100 | 侧栏和标题栏底色不透明度 |
| `composerOpacity` | 0–100 | 输入框底色不透明度 |
| `focusX` / `focusY` | 0–100 | 图片铺满时的裁切对齐位置；图片与窗口同宽高比时变化不明显 |
| `blur` | 0–24 | 图片模糊像素数 |

默认保留客户端原来的字体、文字颜色和语法高亮。菜单、弹窗和代码块保留较实的底色。
若当前模式没有对应 JSON，就显示客户端原样。一个模式只能有一个 JSON。

## 移除与排错

- `stop.bat`：停止本工具的监听器，并移除当前窗口内的皮肤。客户端保持打开。
- 关闭客户端后，内存里的皮肤自然消失，失联十五秒后监听器退出。
- `check.bat`：检查 Node、安装路径、配置、调试连接及注入状态，不输出聊天内容。
- 端口冲突：改 `settings.json` 中的 `debugPort`（默认 9342），完全退出客户端后重试。
- 日志：`%APPDATA%\codex-work-skin\`，包含 `watcher.log`、`watcher.stderr.log` 和启动日志。
- 找不到安装位置时，在 PowerShell 中设置 `$env:CODEX_SKIN_EXE='桌面程序的完整路径'`，再运行 `scripts/start.ps1`。该路径应指向带 resources/app.asar 的桌面程序，不能是 Codex CLI。

## 适配范围与验证边界

本工具是第三方实验性换肤方案，不是官方主题功能。
已参考这台电脑安装的 `OpenAI.Codex 26.1016.8622.0` 静态资源中的 app-shell 标记和颜色变量适配。
只处理该客户端自己的 `app://-` 页面，或安装目录内的 `resources/app.asar/webview/index.html`，并再次检查 app-shell DOM。
不会注入到 HTTPS 浏览器页面、插件沙盒、开发者工具或其他网站。

离线预览是按真实外壳标记重做的示例布局，使用同一套换肤代码；可切换首页/聊天和深浅色。它不是客户端截图，不包含真实聊天，原生控件、字体与窗口尺寸仍可能有差异。
自动化测试覆盖配置校验、目标过滤，以及独立浏览器中的真实 DOM 注入、深浅色切换、重复应用、样式损坏恢复和还原。
0.2.0 已在本机当前登录窗口验证并检查实际截图：全窗口外壳透明、主内容遮罩 30%、侧栏底色 90%、侧栏内部不再叠加底色、图片不透明度 30%，与浅色预览的合成规则一致。真实窗口的深浅色切换和移除未在本次在线会话中主动操作；相应功能已由独立浏览器测试验证。
有些客户端构建可能忽略 Chromium 调试参数；遇到这种情况脚本会报告失败，不会尝试修改安装包或绕过客户端限制。
客户端升级后若 DOM、窗口协议或调试支持变化，可能需要重新适配。

调试端口只指定绑定 127.0.0.1。本机调试连接拥有页面控制权限，因此只在本机使用，不要把端口转发到网络上。

## 开发与来源

运行 `npm test` 执行无依赖单元测试。
`powershell -NoProfile -File scripts/start.ps1 -ValidateOnly` 只验证配置与本机安装识别，不启动、不注入、不更换监听器。
`powershell -NoProfile -File tests/launcher.test.ps1` 用模拟进程检查升级接管、PID 重用和无关进程保护，不操作真实进程。
`node tests/browser-integration.mjs` 使用本机 Chrome 或 Edge 的独立无登录测试配置，执行浏览器集成测试并输出模拟截图；可通过 `CODEX_SKIN_TEST_BROWSER` 指定浏览器完整路径。
